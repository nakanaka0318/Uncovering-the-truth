# 偽りの廷 — Uncovering the Truth

一人で遊ぶ「人狼 × 推理 × ローグライク」ブラウザゲーム。
伏せられた容疑者の札をめくって尋問し、名乗る身分と証言の矛盾から、盤上に潜む**虚偽者**を全員処刑してください。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要・スマホの縦横どちらにも対応）。
GitHub Pages を有効にすれば、そのまま公開できます。

## ルールの要点

- **無辜**は必ず真実を、**虚偽者**（従者・首魁）は必ず嘘を語る。**惑い者**は善側だが証言が当てにならない。
- 善側の身分は重複しない。同じ身分を名乗る者が二人いれば、片方は偽物。
- 尋問は何度でもできるが、鐘撞き・墓守のように**尋問の順番**を数える者もいる。
- 無辜を処刑すると信用−2、惑い者は−1。信用が尽きると解任（敗北）。
- 4章×3審判＋最終審判。審判の合間に聖遺物・道具・休息を選び、章の終わりには行商人と宿がある。
- 累計の審判数で新たな身分（全44種）と聖遺物（16種）が解禁。勝利すると次の階位（難易度）が開く。
- 勝利の後は続きの**外典**へ。外典・壱『深淵の書庫』（超むず）と外典・弐『奈落の大法廷』（激ムズ）は4×4の盤で、複雑な身分と、真実しか語らない裏切り者「潜伏者」が現れる。一度勝てばタイトルから直接挑むこともできる。

## 構成

| パス | 内容 |
| --- | --- |
| `src/js/data.js` | 身分・聖遺物・道具・章・階位のデータ |
| `src/js/logic.js` | 証言の生成、真偽判定、ソルバー、審判の生成 |
| `src/js/game.js` | ラン進行・報酬・行商・自動セーブ |
| `src/js/ui.js` | 画面描画と操作、手ほどき |
| `src/js/audio.js` | Web Audio による生成BGM・効果音 |
| `src/js/portrait.js` | 手続き生成のシルエット肖像 |
| `src/style.css` | 見た目 |
| `build.mjs` | ソースを1枚の `index.html` にまとめる |

盤面は生成のたびにソルバーで検証され、公開情報と矛盾しない「虚偽者の組」が1通り（時に2通り）に絞られるものだけが出題されます。2通り残った時は、道具や聖遺物で見極めます。

## ビルド

```sh
node build.mjs
```
